## What this is

A USB installer for TUR, The Unified Realm: a desktop operating system built on
Fedora Kinoite with bootc. Start a computer from the stick and it installs TUR
onto one whole disk. Read the [installation guide]({{guide_url}}) before you
begin.

## Check the download

Put the medium and `{{sums}}` in one folder, then:

```sh
sha256sum -c --ignore-missing {{sums}}
```

It must print `{{iso}}: OK`. On macOS use `shasum -a 256 {{iso}}`, on Windows
(PowerShell) `Get-FileHash {{iso}} -Algorithm SHA256`, and compare with
`{{iso_sha256}}`.

To check that the checksums (and the medium) are the ones TUR's release
workflow signed, install [cosign](https://github.com/sigstore/cosign/releases)
(version 3) and download the `.sigstore.json` files from this page:

{{#keyless}}
```sh
cosign verify-blob \
  --bundle {{sums}}.keyless.sigstore.json \
  --certificate-identity {{keyless_identity}} \
  --certificate-oidc-issuer {{keyless_issuer}} \
  {{sums}}

cosign verify-blob \
  --bundle {{iso}}.keyless.sigstore.json \
  --certificate-identity {{keyless_identity}} \
  --certificate-oidc-issuer {{keyless_issuer}} \
  {{iso}}
```

Each prints `Verified OK`. The signature names the workflow that made it and is
recorded in Sigstore's public transparency log.
{{/keyless}}
{{#release_key}}

They are also signed with TUR's release key, the key TUR's published images
are signed with. Its public half is attached as
`{{base}}.release-key.pub`:

```sh
cosign verify-blob --key {{base}}.release-key.pub \
  --bundle {{sums}}.release-key.sigstore.json {{sums}}
cosign verify-blob --key {{base}}.release-key.pub \
  --bundle {{iso}}.release-key.sigstore.json {{iso}}
```
{{/release_key}}

## Write the USB stick

The file is a disk image. Write it to the stick **as it is, byte for byte**.
Copying the file onto a formatted stick does not work, and neither does a
tool's "ISO mode" that unpacks it. Writing erases the stick.

- **Windows, Rufus:** select the file, press Start, and when Rufus asks, choose
  **"Write in DD Image mode"**, not ISO Image mode.
- **Windows, macOS or Linux, Fedora Media Writer:** choose "Select .iso file",
  pick the file and the stick, and write.
- **Linux, `dd`:** find the stick with `lsblk -o NAME,SIZE,MODEL,TRAN` (the
  line whose connection is `usb`). **Be certain: `dd` overwrites whatever disk
  you name.** Then write to the whole stick, not to a partition:

  ```sh
  sudo dd if={{iso}} of=/dev/sdX bs=4M conv=fsync status=progress
  ```

Afterwards Windows may offer to format the stick because it cannot read it.
Decline. The [installation guide]({{guide_url}}) has the details, macOS
included, the firmware settings, and what to report back.
