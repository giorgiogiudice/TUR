# TUR-009 — The installer medium's live session and graphical installer (D-23)

(Draft: the results are filled in from the CI runs of pull request 83.)

## How it works

```text
USB stick (ISO 9660 + GPT + EFI system partition; Fedora's shim and GRUB, unchanged)
  boot menu ─┬─ "Try or install TUR"  (default)   tur.live=1        → graphical.target
             └─ "Install TUR (text mode)"  [t]    tur.installer=1   → tur-installer.target

graphical.target (live root = SquashFS of the TUR image + overlay in memory)
  Plasma Login Manager ── autologin ──▶ liveuser ── Plasma ── autostart ──▶ tur-installer-wizard
                                                                              │  (Qt Quick, Tur.Kit,
                                                                              │   runs as liveuser)
                                     pkexec (polkit: org.tur.installer.engine, │  JSON lines on stdout,
                                     liveuser only, medium only)               ▼  "cancel" on stdin
                                                                     tur-install-engine (root)
                                                                              │
tur-installer.target                                                          │
  tur-install (root, first console) ─────── sources ──────▶ engine.sh ◀───────┘
                                                              │ verify payload, checks, disks,
                                                              │ phrase, revalidate,
                                                              ▼
                       bootc install to-disk --source-imgref oci:<medium>/payload:payload \
                           --target-imgref <name> --generic-image --wipe --filesystem ext4 <disk>
                                                              │
                                     log → /var/log/tur-installer/<session>/ on the installed disk
```
