SUMMARY
- What changed: The installer medium starts, by default, a TUR live
  desktop (Plasma, signed in automatically as a live user, nothing kept)
  that opens TUR's graphical installer, a standalone Qt Quick program on
  Tur.Kit with the screens of desktop-experience.md 11.5 and the
  diagnostics drawer. The text installer of ADR-0018 is the boot menu's
  second entry ("Install TUR (text mode)", key t). Both installers use one
  engine (engine.sh) and the same `bootc install to-disk` command; the
  graphical one reaches the engine only through pkexec, one step at a
  time. The installer's log is now kept on the installed disk.
- Why it changed: the owner asked for a live version with a wizard
  installer instead of the text-only one.
